# コードレビュー方針

`/code-review` 実行時、および「レビューして」等の口頭指示時に共通して適用する基準。

## デフォルトのレビューレベル

レベル指定を省略した場合は `medium` を使う(確信度の高い指摘を適度な件数で報告)。

## 必須チェック項目

- **新機能にはテストを必ず伴わせる。** `vitest` によるユニットテストが存在しない新機能・新規ロジックは指摘する(例: `src/pages/Calculator.test.tsx`、`src/utils/calculator.test.ts` のような既存パターンを踏襲)。

## 項目追加時のルール

このプロジェクト固有のレビュー基準が増えた場合は、`CLAUDE.md` 本体ではなく本ファイルに追記する(`CLAUDE.md` の肥大化を避けるため)。
